# Оптимизация скорости и плавности проигрывания видео

## Сделано:

### 1. Увеличен размер BlockingQueue (очередей)
- **Было**: `frames(3)` и `results(3)`
- **Стало**: `frames(12)` и `results(12)`
- **Эффект**: Больший буфер между чтением, обработкой и отображением → более плавное воспроизведение

### 2. Добавлен контроль FPS в VideoReader
- Добавлен параметр `targetFps` в конструктор VideoReader
- Реализована синхронизация по времени между кадрами
- **Использование**: 
  - `targetFps = 0.0` → максимальная скорость (быстро как можно)
  - `targetFps = 30.0` → ровно 30 FPS
  - `targetFps = 60.0` → ровно 60 FPS
- Текущая установка: `0.0` (максимум)

### 3. Добавлены #include для поддержки FPS контроля
- `#include <chrono>` для высокоточных временных измерений
- `#include <thread>` для std::this_thread::sleep_for

## Как использовать:

### Изменение целевого FPS:
В файле [mainwindow.cpp](src/mainwindow.cpp) строка 38:
```cpp
reader = new VideoReader(videoPath, frames, stop, 30.0); // 30 FPS
```

### Возможные значения:
- `0.0` → максимум (без ограничений)
- `24.0` → кино стандарт
- `30.0` → стандартное видео
- `60.0` → высокий FPS

## Дополнительная оптимизация:

Если видео всё ещё заикается, можно:

1. **Уменьшить качество обработки** - пропускать больше Hough кадров:
   Текущая логика: вычисляет Hough если контуров < 2 ИЛИ каждый 3й кадр
   Можно изменить на каждый 4-5й кадр

2. **Снизить разрешение видео** - обрабатывать уменьшенное изображение

3. **Оптимизировать пороги** - если видео чёрно-белое, можно пропустить HSV конверсию
